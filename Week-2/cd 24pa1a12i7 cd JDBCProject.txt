JDBC CRUD Project Documentation

1. Title
Student Database Management System using JDBC and MySQL.

2. Aim
To develop a Java application using JDBC that connects to a MySQL database and performs CRUD (Create, Read, Update, Delete) operations on a Student table.

3. Objective
-Learn JDBC architecture.
-Establish a connection between Java and MySQL.
-Execute SQL statements using JDBC.
-Perform CRUD operations.
-Display database records in Java.

6. Introduction
Java Database Connectivity (JDBC) is an API that enables Java applications to communicate with relational databases. It provides classes and interfaces to establish a connection, execute SQL queries, and process results.
In this project, JDBC is used to connect a Java application to a MySQL database and perform CRUD operations on student records.

13.JAVA program

```java
import java.sql.*;

public class StudentJDBC {

    // Database credentials
    static final String URL = "jdbc:mysql://localhost:3306/studentdb";
    static final String USER = "javauser";
    static final String PASSWORD = "password";

    public static void main(String[] args) {

        try {
            // Load JDBC Driver
            Class.forName("com.mysql.cj.jdbc.Driver");

            // Establish Connection
            Connection con = DriverManager.getConnection(URL, USER, PASSWORD);

            // Create Statement
            Statement stmt = con.createStatement();

            // Create Student Table
            String createTable = "CREATE TABLE IF NOT EXISTS student (" +
                                 "rollno INT PRIMARY KEY," +
                                 "name VARCHAR(50)," +
                                 "address VARCHAR(100))";

            stmt.execute(createTable);
            System.out.println("Table created successfully.");

            // Insert Records
            stmt.executeUpdate("INSERT INTO student VALUES (1,'Ravi','Chennai')");
            stmt.executeUpdate("INSERT INTO student VALUES (2,'John','Delhi')");
            stmt.executeUpdate("INSERT INTO student VALUES (3,'Anita','Bangalore')");

            System.out.println("Records inserted successfully.");

            // Update Record
            stmt.executeUpdate(
                "UPDATE student SET address='Mumbai' WHERE rollno=2"
            );

            System.out.println("Record updated successfully.");

            // Delete Record
            stmt.executeUpdate(
                "DELETE FROM student WHERE rollno=3"
            );

            System.out.println("Record deleted successfully.");

            // Retrieve and Display Records
            ResultSet rs = stmt.executeQuery("SELECT * FROM student");

            System.out.println("\nStudent Records");
            System.out.println("-------------------------------------");
            System.out.printf("%-10s %-15s %-15s%n", "Roll No", "Name", "Address");
            System.out.println("-------------------------------------");

            while (rs.next()) {
                System.out.printf(
                    "%-10d %-15s %-15s%n",
                    rs.getInt("rollno"),
                    rs.getString("name"),
                    rs.getString("address")
                );
            }

            System.out.println("-------------------------------------");

            // Close Resources
            rs.close();
            stmt.close();
            con.close();

        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}
```
